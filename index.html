🎫 電子票（QR Code 版）啟用與進出站規則：

  • 何時啟用（Activate）：請於 12/10（Day 1）準備進入兒島以南（或丸龜站出站）時再點擊啟用，一旦啟用即開始計算連續 3 天（12/10 – 12/12），切勿提前一天按啟用。
  • 動態 QR Code 規定：過閘門與查票時需保持網路連線、調高螢幕亮度開啟即時網頁（不接受截圖）。隨身請務必攜帶行動電源。
  • 進出站方式：主要車站（丸龜、高知、JR松山）有 QR Code 掃描閘門可直接感應；若遇無掃描機的閘門或跨區路段（岡山 ⇄ 兒島），請走人工通道同時出示「手機電子票」與「紙本補票券」。
  • 座位與劃位規定：電子票含「普通車自由席」（建議提早 15 分鐘排隊選左側 D/E 席看海景與溪谷）；若想搭指定席，可持電子票與護照至 JR 四國主要車站綠色窗口加購外國人專用指定席回數券（4張 ¥1,200）。

🚨 跨區補票與路面電車「刷卡差異」重點提醒：

  • 【D1 補票】岡山 ➔ 兒島（¥1,270）：抵達岡山站後，先至 2F 綠色售票機買好「岡山 ➔ 兒島」紙本乘車券＋自由席特急券，直接放入自動驗票閘門進站。
  • 【D3 補票】兒島 ➔ 岡山（¥1,270）：早上 06:40 到 JR 松山站時，先在綠色窗口／售票機買好「兒島 ➔ 岡山」紙本車票，進松山站掃手機 QR Code，到岡山站走人工通道出示兩者直接出站（免排隊精算補票，省時間衝岡山城！）。
  • 【D2 高知路面電車】土佐電交通：✅ 可用電子周遊券（下車向司機出示手機動態畫面即可）。
  • 【D2-D3 松山路面電車】伊予鐵道：❌ 不可用周遊券！（2026/3/7 起已退出周遊券範圍），往返道後溫泉與 JR 松山站請直接刷 ICOCA。
  • 【D3 岡山城正案底線】11:30 前必須離開岡山城；若 10:30 仍未抵達岡山，則放棄岡山城行程。

🛍️ 四國・岡山必買伴手禮精選推薦

網羅高知、松山道後及最後岡山機場最受歡迎的人氣土產，方便您在行程中挑選：

🍊 高知必買特產

  • 野村煎豆加工店「米蕾餅乾 (ミレービスケット)」：鹹甜酥脆的昭和古早味國民餅乾，一口接一口停不下來。
  • 水車亭「鹽味地瓜條 (塩けんぴ)」：使用室戶海洋深層水鹽與糖蜜，甜鹹交織、脆度十足。
  • 馬路村「柚子醋醬 (ポン酢しょうゆ)」：高知產有機柚子與鰹魚醬油完美結合，火鍋或沾醬絕配。
  • 滿天之星「焙茶大福」：香濃焙茶粉包裹紅豆與鮮奶油內餡，茶香四溢。

♨️ 松山 / 道後溫泉必買

  • 一六本舖「一六毛巾捲蛋糕 (一六タルト)」：愛媛最具代表性的柚子風味海綿蛋糕捲。
  • つぼや菓子舗「少爺糰子 (坊っちゃん団子)」：夏目漱石小說名作靈感的三色紅豆手工糰子。
  • 10 FACTORY / 各大名產店「蜜柑汁 / 柑橘果餅」：愛媛必喝的100%水龍頭/瓶裝蜜柑原汁與果凍。
  • 今治毛巾 (今治タオル)：吸水力極佳、觸感頂級的日本第一毛巾製品。

✈️ 岡山機場必買 / 最後補貨

  • 山方永壽堂 / 廣榮堂「吉備糰子 (きびだんご)」：桃太郎傳說經典Ｑ軟小米麻糬，可愛包裝送禮首選。
  • 岡山白桃起司貓舌餅乾：濃郁白桃香氣結合起司夾心，機場熱銷第一名。
  • 日本航空 (JAL)「御翔印」：僅在岡山機場限定販售的機場版御朱印（航空迷必收）。
  • 瀨戶內海蝦餅 / 岡山白桃果凍：機場國內線與免稅店皆可輕鬆入手。
